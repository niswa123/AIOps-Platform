# AIOps-Platform

Observability, cost tracking, distributed tracing, and governance platform for AI Agents and MCP servers.

## Tech Stack
- **Backend:** FastAPI, Python, clickhouse-connect, aiokafka
- **Storage:** ClickHouse, PostgreSQL, Redis
- **Streaming:** Redpanda (Kafka-compatible)
- **Frontend:** Next.js (App Router, Tailwind CSS, TypeScript)
- **Deployment:** Docker / Kubernetes
