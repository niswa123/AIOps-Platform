# PRODUCT.md - AIOps Platform

## Overview
AIOps Platform is an open-source & enterprise-grade observability, tracing, cost management, and governance platform for AI Agents, LLM calls, and Model Context Protocol (MCP) servers. Think "Datadog for the AI era."

## Core Purpose
Provide developers and enterprise teams absolute visibility into their AI agent infrastructure—optimizing costs, troubleshooting failures, debugging distributed agent chains, and monitoring tool executions in real-time.

## Register
`product` (A tool where design serves utility, performance, and density).

## Target Users
1. **AI Engineers & Developers:** Building agentic systems (CrewAI, LangChain, Autogen) needing local or cloud tracing and prompt debugging.
2. **CTOs & Engineering Managers:** Looking to optimize rising token costs, monitor SLA/latency, and audit agent-to-tool operations.
3. **Platform / DevOps Engineers:** Overseeing Kubernetes deploys, Kafka throughput, and ClickHouse cluster scalability.

## Brand Principles & Tone
*   **Performance-obsessed:** The interface must feel instant, handling high-throughput telemetry updates without UI lags.
*   **Technical & Honest:** Direct data representations, monospaced outputs, clean metric charts.
*   **Non-intrusive:** Stays out of the way of the code. Fast configuration, straightforward navigation.

## Anti-References & Bans
*   **The SaaS Blue Template:** No generic navy-blue gradients or rounded cards with plain blue drop shadows.
*   **Unnecessary Modals:** Avoid multi-nested overlays. Keep debugging inline, using collapsible panels or master-detail side-sheets.
*   **Vague Status Indicators:** Green dot is not enough. Provide state indicators with concrete throughput/latency metrics.
*   **AI Clichés:** No glowing purple mesh gradients or futuristic AI animations. This is a monitoring tool, not a marketing website.
